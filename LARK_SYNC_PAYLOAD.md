# Lark Sync Webhook Payload Reference

This document outlines the JSON payload sent by the sync scheduler to the Lark webhook endpoint.

## Webhook Endpoint Configuration
* **Environment Variable**: `NXLINK_WEBHOOK_URL`
* **Default Target**: `https://asia-southeast1-planet-group-d2436.cloudfunctions.net/jobApplication`
* **Headers Sent**:
  * `Content-Type: application/json`
  * `X-Client-Id`: (From `NXLINK_WEBHOOK_CLIENT_ID`)
  * `X-Client-Secret`: (From `NXLINK_WEBHOOK_CLIENT_SECRET`)

---

## Field Mapping Table

| JSON Payload Key | Source Column / Parser Origin | Example Value | Description |
| :--- | :--- | :--- | :--- |
| **`Conversation ID`** | `conv.id` / `convId` | `"3046322"` | Unique ID of the NxLink conversation |
| **`Customer Name`** | `customer_name` / `meta.customer_name` | `"Quinn"` | Candidate full name |
| **`Phone Number`** | `phone_number` / `meta.phone_number` | `"0123456789"` | Candidate mobile number |
| **`Company Name`** | `company_name` | `null` | Customer company (usually null for candidates) |
| **`Email Address`** | `email_address` | `"quinn@example.com"` | Candidate email address |
| **`Tags`** | `conversation_tags` | `["Hot Lead", "Job Application"]` | Tags assigned to the conversation |
| **`Full Summary`** | `conversation_summary` | `"..."` | Detailed summary generated by AI bot |
| **`Sentiment`** | `customer_sentiment` | `"Positive"` | Sentiment of the candidate |
| **`Next Steps`** | `next_steps` | `"Arrange interview"` | Next action items generated by AI bot |
| **`Call Audio URL`** | `call_audio_url` | `"https://..."` | Link to the voice call audio recording |
| **`Conversation Date`** | `conversation_date` | `"2026-08-24"` | Date of interaction |
| **`Position Applied`** | `position_applied` | `"Retail Sales Associate"` | Role candidate is applying for |
| **`Gender`** | `gender` | `"Male"` | Candidate gender |
| **`Age`** | `age` | `"22"` | Candidate age |
| **`Highest Qualification`**| `qualification` | `"Diploma"` | Candidate qualification / education level |
| **`Address`** | `address` | `"11, Jalan 222..."` | Candidate residential address |
| **`Job Title`** | `job_title` | `"Sales Executive"` | Candidate current/previous job title |
| **`Working Experience`** | `working_experience` | `"ABC Sdn Bhd..."` | Summary of working experience |
| **`Reason`** | `reason` | `"Seeking growth"` | Reason for leaving/applying |
| **`Current Salary`** | `current_salary` | `"RM2,500"` | Candidate current salary |
| **`Expected Salary`** | `expected_salary` | `"RM3,000"` | Candidate expected salary |
| **`Notice Period`** | `notice_period` | `"1 Month"` | Notice period before starting |
| **`Photo URL`** | `photo` | `"https://..."` | Link to candidate's profile/uploaded photo |
